# Playwright Python Hybrid Automation Framework

## Framework Features

- Playwright with Python
- Pytest Framework
- Page Object Model
- Data Driven Testing
- HTML Reporting
- Screenshot on Failure
- Parallel Execution
- CI/CD Integration

## Test Scenarios

1. Valid Login
2. Invalid Login
3. Add Product To Cart
4. Complete Checkout Flow
5. Logout Functionality

## Installation

pip install -r requirements.txt
playwright install

## Run Tests

pytest
